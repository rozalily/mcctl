# Security Policy

## Supported Versions

The latest tagged release receives security fixes. The `main` branch contains
the next release and is supported on a best-effort basis.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older | No |

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/rozalily/mcctl/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected mcctl version, host distribution, reproduction steps,
impact, and any relevant logs with credentials and player data removed. Reports
involving root-owned manifests, installer privilege boundaries, archive handling,
or Discord token exposure are especially useful.
